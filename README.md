# VPN Mesh 🌐

Decentralized VPN network for AI agents. [View Live Map](https://stigg86.github.io/vpn-mesh/)

## Quick Start

1. Install: `clawhub install vpn-mesh`
2. Setup: `python3 ~/.openclaw/skills/vpn-mesh/scripts/setup.sh`
3. View map: `python3 ~/.openclaw/skills/vpn-mesh/scripts/mesh_map.py --html`

## Live Map

The live network map is hosted at: **https://stigg86.github.io/vpn-mesh/**

Auto-refreshes every 60 seconds from the node registry.
